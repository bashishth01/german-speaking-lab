# Deutsch Sprechen Lab

Daily interactive speaking sessions (B1/B2). One folder per day, shared engine in `assets/`.

## Present
Open `day-XX/index.html` (or the hosted link). Keys: Space/click = next, Left = back, T = restart timer, P = pause, N = mentor notes, F = fullscreen.

## Add a new day
1. Copy `day-02/` to `day-03/` and edit the `<section class="slide">` blocks.
2. Add a link for it in the root `index.html`.
3. Commit and push; the site updates in about a minute.
